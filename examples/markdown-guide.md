# 从一段文字，到一个阅读页面

一个想法不一定要写成应用。项目介绍、开发记录、使用教程，也可以从 **Markdown** 开始，发布成一张值得分享的网页。

## 写作时，专注于内容

标题负责层次，段落负责节奏。用普通文本组织想法，阅读时再交给排版。

> 好的展示，不只是把内容放上去。它也应该让人愿意读下去。

你可以使用 **加粗**、*强调*、~~删除线~~，也可以放入 [Quickshare 的作品展厅](https://www.t5t6.com/)。

## 一条命令完成发布

保存为 `article.md`，在已连接 Quickshare 的电脑上运行：

```bash
quickshare publish ./article.md \
  --slug my-notes \
  --title "我的开发手记" \
  --tags 文章,开发 --capture
```

`--capture` 会截取排版后的页面作为封面。继续修改内容时，使用 `update`，分享链接保持不变。

```javascript
const idea = "把有趣的想法做出来";
const share = (message) => console.log(message);
share(idea);
```

## 格式，按内容选择

| 内容类型 | 适合的格式 | 展示方式 |
| --- | --- | --- |
| 项目介绍与开发手记 | Markdown | 排版后的阅读页面 |
| 小游戏和交互实验 | HTML | 可直接操作的作品 |
| 使用教程和说明文档 | Markdown | 目录、表格与代码块 |

### 图片与文件

图片可以引用公开的 HTTPS 地址。相对路径图片不会自动上传，需要先托管图片或改为公开链接。

### 分享与下载

阅读页面可以复制链接、全屏打开，也可以下载为独立 HTML。正文样式和代码高亮随文件保存，不需要在线下载字体或脚本。
