# Social card fonts

Noto Sans SC, SIL Open Font License 1.1 (OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc
The upstream NotoSansSC[wght].ttf was instantiated at weights 400 and 600 with fontTools.varLib.instancer (updateFontNames=True). Static instances are required because the SVG renderer does not select variable weights reliably. No glyphs removed. These files are used only by the server's own title-card renderer and are not served as user content.
